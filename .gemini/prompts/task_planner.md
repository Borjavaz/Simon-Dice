# Tarea: Planificación de Tareas (Roadmap de DAM)
"Borja tiene una nueva entrega o funcionalidad que desarrollar.
Ayúdale a dividir el trabajo siguiendo la metodología Agile (Sprints cortos).
Requisitos:
1. **Priorización:** Diferencia entre lo basico para q funcione y lo extra
2. **Pasos lógicos:** No digas 'haz la UI', di '1. Crea el modelo, 2. Define el Repository, 3. Configura el ViewModel'.
3. **Estimación:** Calcula cuánto tiempo debería dedicarle a cada tarea.
4. **Checklist:** Crea una lista de tareas que Borja pueda ir marcando.
